# workflow-laravel

Independent Laravel adapter for `webong/workflow`.

Install `webong/workflow-laravel` from a repository containing this package archive.
This nested manifest is not discoverable through a VCS repository pointing at
the monorepo root; see [package installation](https://github.com/webong/workflow/blob/main/docs/packages.md).

PHP namespace: `Webong\WorkFlow\Laravel`. Core is required independently;
its package has no adapter dependencies or Laravel discovery metadata.
